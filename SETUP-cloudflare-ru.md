# Свой сервер на Cloudflare: настройка владельцем (один раз, ~20 минут, бесплатно, без домена)

Сервер хранит аккаунты и **только зашифрованные** данные семей. Ключи шифрования создаются на телефонах: пароля, ключа семьи, заметок, событий, фамилии, даты рождения и пола сервер не видит. Командную строку и свой домен иметь не нужно: всё делается в браузере.

## Часть 1. База данных
1. Зарегистрируйтесь на https://dash.cloudflare.com (бесплатно, нужна только почта).
2. Слева **Storage & Databases → D1 SQL Database → Create database**. Имя: `comfortable-life`.
3. Откройте базу → вкладка **Console** → вставьте весь файл `cloudflare/schema.sql` → **Execute**.

## Часть 2. Сервер (Worker)
1. Слева **Workers & Pages → Create → Create Worker** (шаблон Hello World). Имя: `comfortable-life` → **Deploy**.
2. Кнопка **Edit code** → удалите всё и вставьте содержимое `cloudflare/worker.js` → **Deploy**.
3. **Settings → Bindings → Add → D1 database**: Variable name строго `DB`, база `comfortable-life` → Save.
4. Адрес сервера виден вверху: `https://comfortable-life.ИМЯ.workers.dev`. Откройте его в браузере: должен показаться текст `{"ok":true,"app":"comfortable-life-server",...}`.
5. Вставьте этот адрес в `config.js` приложения и загрузите приложение на GitHub, как раньше.

Секреты добавляются так: Worker → **Settings → Variables and Secrets → Add** (тип Secret), потом **Deploy**.

## Часть 3. Письма с кодами (выберите один способ)
Без этого код подтверждения почты не требуется: любой сможет зарегистрироваться на чужую почту. Для тестов с близкими это терпимо, для публичного запуска нет.

**Способ A. Brevo (удобнее, 300 писем в день).** Зарегистрируйтесь на https://www.brevo.com, в «Senders» подтвердите свой адрес отправителя (придёт письмо), в «SMTP & API → API keys» создайте ключ. Секреты: `BREVO_KEY` = ключ, `MAIL_FROM` = подтверждённый адрес. Письма с адресов вроде gmail.com могут попадать в спам, это ограничение отправки без своего домена.

**Способ B. Через Google (без регистрации в сторонних сервисах, ~100 писем в день).** Файл `cloudflare/mail-relay.gs` — маленький скрипт для Google Apps Script; инструкция в его начале. Секреты: `MAIL_RELAY_URL` и `MAIL_RELAY_SECRET`.

## Часть 4. ИИ-ассистент (по желанию)
Если заданы оба ключа, используется GigaChat, при сбое Claude. Лимит 40 сообщений в сутки на аккаунт.
- **GigaChat:** ключ авторизации из https://developers.sber.ru/studio → секрет `GIGACHAT_AUTH`. По желанию `GIGACHAT_SCOPE` (по умолчанию `GIGACHAT_API_PERS`), `GIGACHAT_MODEL`. Не знаю, пускают ли серверы Сбера запросы из Cloudflare: проверьте.
- **Claude:** ключ с https://console.anthropic.com → секрет `ANTHROPIC_API_KEY`.
Тексты вопросов уходят с сервера в Сбер или Anthropic: укажите это в политике приватности.

## Часть 5. Вход через Яндекс
1. https://oauth.yandex.ru/client/new → «Для авторизации пользователей» → платформа **Веб-сервисы**, Redirect URI = адрес вашего сервера со слешем на конце: `https://comfortable-life.ИМЯ.workers.dev/`. Доступы: `iot:view`, `iot:control`.
2. Секреты: `YANDEX_CLIENT_ID` = ID, `YANDEX_CLIENT_SECRET` = пароль. (`YANDEX_REDIRECT` нужен, только если адрес в Яндексе другой.)
3. Токен каждого человека хранится на сервере в его аккаунте. Для публичного запуска Яндекс может потребовать модерацию приложения.

## Как устроена защита
- **Пароль** на сервер не уходит: отправляется только результат PBKDF2, сервер хеширует его ещё раз.
- **Главный ключ аккаунта** создаётся на телефоне и заперт паролем и **ключом восстановления** (26 символов, показывается один раз при регистрации). Сервер хранит только запертые копии.
- **Ключ семьи** создаёт телефон. Для каждого участника он запирается его открытым ключом (ECDH P-256). Новый участник получает ключ, когда телефон кого-то из семьи окажется онлайн (обычно секунды).
- **Что видит сервер:** почту, ID, имя (для приглашений), открытый ключ, размер и время изменения зашифрованных блоков, токен Яндекса, тексты вопросов к ИИ. Заметки, события, ключи и пароль не видит.
- **Забыли пароль:** вход через ключ восстановления. Нет ни пароля, ни ключа: сменить пароль можно только создав аккаунт заново, старые данные не открыть. Данные семьи останутся у остальных участников.
- **Код безопасности** (отпечаток открытого ключа) показан на экране «Семья» у каждого участника: сверьте его по телефону с близкими, чтобы исключить подмену ключа сервером.
- Данные только на телефоне (не помеченные «для семьи») на сервер не попадают вообще.

## Бесплатные лимиты Cloudflare (на момент написания)
100 000 запросов в сутки на Worker; D1: 5 ГБ, 100 000 записей в сутки. Приложение раз в 8 секунд спрашивает только номер версии, пока открыто: один телефон, всё время открытый на экране, это около 10 000 запросов в сутки. Для десятков одновременных пользователей понадобится платный тариф (от 5 долларов в месяц) или реже опрашивать.

## Важно
- Версия 0.6.0 несовместима со старым сервером на Apps Script (папка `server-legacy-apps-script`). Аккаунты и семьи придётся создать заново.
- Закон о хранении персональных данных россиян (152-ФЗ): серверы Cloudflare за границей. Для личного использования это не мешает, для публичного запуска в России понадобится решение (российский хостинг, согласия, уведомление Роскомнадзора).
- Проверено на заглушках (Cloudflare D1 заменена локальной SQLite, внешние сервисы имитированы). На настоящем Cloudflare, Яндексе, GigaChat и почте не запускалось.
