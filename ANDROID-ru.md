# Приложение на телефон: три этапа

Сейчас Comfortable life это PWA: сайт, который ставится на телефон как приложение. Ниже путь от простого к полному.

## Этап 1. Поставить как приложение (работает уже сейчас, 1 минута)
- **Android (Chrome):** откройте адрес приложения → меню ⋮ → «Установить приложение» (или «Добавить на главный экран»).
- **iPhone (Safari):** откройте адрес → кнопка «Поделиться» → «На экран «Домой»».
Иконка, полноэкранный режим и работа без интернета уже есть.

## Этап 2. APK для Android (без программирования)
1. Откройте https://www.pwabuilder.com и вставьте адрес приложения на GitHub Pages. Он покажет оценку: манифест и service worker в приложении есть.
2. Нажмите **Package for stores → Android**. Заполните имя пакета (например `com.comfortablelife.app`), версию, оставьте остальное по умолчанию.
3. Скачайте архив. Внутри файл `.apk` (для установки напрямую) и `.aab` (для Google Play), а также ключ подписи и пароль. **Сохраните ключ и пароль: потеряете — не сможете обновлять приложение.**
4. Установка APK на свой телефон: перенесите файл, разрешите «установку из неизвестных источников». Для Google Play нужен аккаунт разработчика (разовый платёж 25 долларов; из России оплата может быть затруднена).

Это оболочка над вашим сайтом (TWA): обновляется вместе с сайтом, но доступа к шагомеру и датчикам телефона не даёт.

## Этап 3. Полноценное приложение с шагами из Здоровья
Нужен проект Capacitor + плагин Health Connect (Android) и HealthKit (iPhone). Для сборки нужны Android Studio на компьютере (для iPhone ещё Mac и аккаунт Apple Developer, 99 долларов в год). Этот этап я готовлю отдельно: пришлите, на чём вы работаете (Windows виден по скриншотам) и есть ли Android Studio.

Что в этом архиве уже подготовлено: манифест с отдельными иконками (обычная и маскируемая), `id` приложения.
